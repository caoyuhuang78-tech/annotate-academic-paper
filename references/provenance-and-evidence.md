# 段落溯源与主张—证据表

## 从 PDF 定位到 HTML

先登记原件标题、版本或 DOI、PDF 总页数和可取得的文件摘要值。按阅读顺序划分来源块，给每块分配唯一 ID。翻译、批注和证据表共同引用同一个 ID。修订时，同一来源块沿用已有 ID。

| 字段 | 记录内容 |
| --- | --- |
| 块 ID 与类型 | 例如 `p-0042`、`fig-04`、`tbl-02`。区分正文、图、图注、表、公式、脚注和参考文献等。 |
| PDF 位置 | PDF 阅读器中从 1 开始的页序，必要时同时记录原刊页码。跨页块逐页记录其片段。 |
| 章节路径 | 原文节名和小节名。无节名时可用“首页信息”“参考文献”等可复核的位置说明。 |
| 定位线索 | 可复制文本块保留一段原样连续的短英文，优先选在该位置唯一的片段。图、表、公式或难以可靠转写的内容用编号、面板、行列、页内区域或核验过的裁图坐标定位。 |
| 原文与校对记录 | 记录完整英文文本或视觉块的来源、阅读顺序、必要的排版规范化以及尚待核实的问题。行号只有在确实存在可复核行号时才使用。 |
| HTML 锚点 | 例如 `#p-0042`。若用 `data-source-id` 绑定译文或批注，其值应指向同一个来源块。 |

在英文上方或旁边显示定位行，例如“PDF 第 4–5 页 · 原刊第 126–127 页 · Results › Deformation · p-0042”。将定位行放在英文本身的容器之外，使逐块回读时只提取英文。图表的编号和定位同样可见。短摘录留在清单里即可，避免在页面重复整段英文。原始文件位置可用于本地工作清单，面向他人分享的 HTML 使用书目信息、原件指纹与页码定位。

## 从主张追到证据

选择摘要、结果、讨论或结论中支撑论文主线的主张。一行处理一个可核实的判断。作者在同一句里给出多个结论且证据范围不同时，分别成行。对研究对象、样本范围、比较基线、效应大小、单位和限定词按原文处理。

| 列 | 写法 |
| --- | --- |
| 作者主张 | 准确概括主张及其范围，并链接到主张出现的原文块。 |
| 证据与出处 | 概括实际观察、实验、推导或引用，附结果块的页内链接及 PDF 页码、图表面板或公式号。多项证据分别链接。二手引用注明来自该论文转述。 |
| 支撑程度 | 用“直接支持”“部分支持”“未给出可核实的证据”或“与所列证据冲突”等文字，并简述判断理由。来源未核实与论文未报告证据应分别表述。 |
| 局限或待验证 | 写清证据的适用范围，指出仍需的数据、对照或检验。批注者推断明确标为“批注推断”。 |

例如，论文根据同一案例的回顾性时间序列主张“可检测灾前加速，并用于实时预警”。第一行链接至显示加速的曲线及观测时间，可评价为直接支持该案例的回顾性识别。第二行链接至预警主张及已有回算，说明真实告警提前量仍需按观测日期滚动验证。示例用于说明表的写法，制作实际 HTML 时应使用当前论文的定位信息和证据。

证据表放在论证总览附近，并在章节导航提供入口。锚点指向包含英文、译文与批注的对应行，确保离线可点。使用带列标题的 HTML 表格，窄屏在表格自身区域横向滚动或按行展示各列标签。

## 核对

- 根据 PDF 逐页枚举内容，检查页序、跨栏及跨页合并，保证同一原文片段只进入一个主原文块。以最终 HTML 为对象，逐块比较英文文字和源版面，检查每项图表和符号。
- 检查每个来源 ID 唯一、链接目标存在，定位行和内部清单指向同一页和小节。视觉块定位到具体图表或页内区域。
- 检查证据表的链接是否指向真正展示相关结果的块。主张出现的摘要或讨论段可作为主张出处；支撑它的实测、实验或推导需另有可追溯来源。未找到相关结果时写明证据缺口。
